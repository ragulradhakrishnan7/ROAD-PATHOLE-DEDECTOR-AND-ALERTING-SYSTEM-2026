# 📌 Project Synopsis

## 1. Project Title
**Road Pothole Detector and Alerting System**

## 2. Category
Artificial Intelligence, Computer Vision, Full-Stack Web Development, Geospatial Systems

## 3. Objective
To build an automated, scalable end-to-end system that detects road potholes using deep learning, geotags their location, calculates hazard severity, alerts drivers in real time, and provides an admin dashboard for infrastructure management.

## 4. Key Modules
1. **AI Computer Vision Engine**: YOLOv8 + OpenCV frame processing.
2. **FastAPI REST Backend**: JWT auth, detection endpoints, SQLAlchemy database ORM.
3. **React Web Frontend**: Responsive dark/light mode UI, Framer Motion animations.
4. **GIS Hazard Map**: Interactive Leaflet marker map and heatmap visualization.
5. **Real-time Alerting Engine**: Audio hazard warning and notification dispatch.
6. **Admin Management Portal**: Analytics, user management, and pothole repair tracking.

## 5. System Deliverables
- Full Source Code (Frontend, Backend, AI, Database).
- Complete Documentation & Setup Guides.
- Docker Containerization & CI/CD Pipeline.
- Automated Test Suite (Pytest).
